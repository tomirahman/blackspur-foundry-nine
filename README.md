BLACKSPUR is a round-based tactical first-person shooter that runs in the browser on three.js: two teams of five, a foundry map called Foundry Nine with two charge sites, an economy that pays for every kill and every round, an armoury between rounds, hitscan gunplay with recoil that punishes firing on the move, and bots that take lanes, hold angles, plant the charge, rotate and cut the fuse. Built as a single-player game against bots, from static files with no build step.

## Run it

```sh
node serve.ts
```
